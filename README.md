# High Look Steel Furniture

Static, mobile-first website for HIGH LOOK STEEL FURNITURE.

## Files
- `index.html` — complete semantic page, SEO and LocalBusiness schema
- `styles.css` — responsive premium dark/gold industrial design
- `script.js` — mobile menu, before/after drag, gallery filters/lightbox, enquiry-to-WhatsApp
- `assets/` — local favicon and Open Graph preview

## Deploy
Upload the folder contents to any static host (GitHub Pages, Netlify, Vercel, Hostinger, etc.).

## Replace visuals
The current furniture visuals are CSS artwork so the site has no broken image dependencies. Replace the `.visual-*` and `.product-visual` elements with real `<img>` elements when workshop/product photos are available, keeping descriptive `alt` text.
